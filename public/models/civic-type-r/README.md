# Civic Type R FL5 reference model

This is original geometry authored in Blender 5.1.2 for this project.
It is a reference-based reconstruction, not Honda CAD or a verified 1:1 scan.
Do not present it as a manufacturer-approved or dimensionally certified model.

Editable source: `assets/showcase/civic-type-r-fl5.blend`
Reproducible authoring script: `scripts/blender/build-civic.py`
Web export: `civic-type-r-fl5.glb`, Draco compressed glTF 2.0.

The source uses metre units. Website coordinates are +Y up, +Z forward;
the right hand driver is at negative X. Named paint, glass, lamp, wheel,
steering and wiper objects are consumed by `src/js/showcase/car-asset.js`.

References studied, not bundled as textures or copied as geometry:
- Honda Malaysia dimensions: https://www.honda.com.my/model/type-r/spec
- FL5 side profile: https://hypebeast.com/2023/1/honda-civic-type-r-fl5-review
- RHD cabin photography: https://car.watch.impress.co.jp/docs/news/photo/1436350.html
- Front photography: https://www.carsensor.net/contents/testdrive/category_70/_67402.html

No Sketchfab or DownloadFree3D model is included in this asset. Honda and
Civic Type R names and insignia identify the depicted vehicle.
